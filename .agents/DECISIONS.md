# Decisions

## DEC-0001 — Protocol-first Repository
- **Decision**: CEP is developed as a protocol and standards repository first, reference implementation second.
- **Rationale**: The core value is semantic interoperability.
- **Status**: Accepted.

## DEC-0002 — Semantic Envelope as Canonical Interchange Object
- **Decision**: Semantic Envelope is the canonical transport structure for CEP-compatible context.
- **Rationale**: Prevents context loss.
- **Status**: Accepted.

## DEC-0003 — RealityGapBench First
- **Decision**: RealityGapBench is the first benchmark family implemented.
- **Rationale**: Clearest category-creation wedge.
- **Status**: Accepted.

## DEC-0004 — Evidence-backed Settlement
- **Decision**: CEP benchmarks must preserve evidence and settlement semantics.
- **Status**: Accepted.
