# Decisions

## DEC-0001 — Protocol-first Repository
- **Decision**: CEP is developed as a protocol and standards repository first, reference implementation second.
- **Rationale**: The core value is semantic interoperability.
- **Status**: Accepted.

## DEC-0002 — Semantic Envelope as Canonical Interchange Object
- **Decision**: Semantic Envelope is the canonical transport structure for CEP-compatible context.
- **Rationale**: Prevents context loss.
- **Status**: Accepted.

## DEC-0003 — RealityGapBench First
- **Decision**: RealityGapBench is the first benchmark family implemented.
- **Rationale**: Clearest category-creation wedge.
- **Status**: Accepted.

## DEC-0004 — Evidence-backed Settlement
- **Decision**: CEP benchmarks must preserve evidence and settlement semantics.
- **Status**: Accepted.

## DEC-0005 — GodSpeed profiles live in cep as thin layers over the full envelope schema
- **Decision**: The six initial GodSpeed profiles (`semantic_snapshot`, `authority_request`, `authority_decision`, `execution_trace`, `evidence_packet`, `settlement_packet`) are defined in this neutral repo as `allOf [full-envelope $ref, tightening]` schemas generated by one script (`tools/generate_godspeed_profiles.py`), with a shared conformance corpus generated by `tools/generate_godspeed_fixtures.py`. The full envelope schema stays the single source of truth; profiles add requirements only, never new top-level fields (CEP-0008 §18, §39).
- **Rationale**: CEP-0008 §18 allows profiles. No consuming system (Cognate, SEA-Forge, RealityTrace) may privately own the cross-stack contract.
- **Status**: Accepted (operator brief 2026-10-04).

## DEC-0006 — world_ref is carried in `scope`; DomainForge defines its grammar
- **Decision**: `scope.world_ref` pins the immutable semantic-world revision; `scope.world_alias` and `scope.world_label` are optional, non-authoritative. The grammar is defined once in DomainForge (`docs/reference/sea-application-contract.md` 14.1); the schema pattern here is a mirror, pinned by vendored DomainForge golden vectors (`schemas/vendored/world_ref/golden-vectors.json`) and a drift test. A profile declaration is carried at `extensions["cep.profile"]` (§18.2/§18.3).
- **Rationale**: scope is the evaluation context (§7.1/§52); no second identity scheme is introduced.
- **Status**: Accepted.

## DEC-0007 — Validator gains `allOf`
- **Decision**: `schema_profile` and `schema_value` support `allOf` (errors from all branches are reported). Needed so profiles can layer over the base schema without copying it.
- **Status**: Accepted.
