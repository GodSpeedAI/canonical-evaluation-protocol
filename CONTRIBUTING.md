# Contributing to Canonical Evaluation Protocol (CEP)

We welcome contributions to the specifications, benchmark definitions, schemas, and implementations.

## RFC Process
All protocol modifications must go through the RFC process under the `rfc/` directory.

## Conformance & Anti-Collapse Rules
Any proposed changes must preserve the fundamental distinctions defined in CEP-0000 and verified in CEP-0010 conformance tests.
